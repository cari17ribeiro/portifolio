Pipeline de Limpeza de OS

Pipeline SQL para tratar ordens de servico de manutencao, identificar OS sem data fim, detectar intervalos sobrepostos por equipamento e consolidar paradas reais para calcular a disponibilidade mensal sem duplicidade.

Apresentacao do projeto

Objetivo

Preparar a base de OS para o calculo de disponibilidade mensal, evitando que registros incompletos ou sobrepostos distorcam o indicador.

OS abertas

OS com inicio real e sem fim real sao classificadas como pendencia de qualidade e separadas do fechamento mensal.

Sobreposicoes

Intervalos que se cruzam para o mesmo equipamento sao detectados com funcoes de janela e consolidados em blocos unicos de parada.

Disponibilidade

A tabela final entrega horas calendario, horas indisponiveis, quantidade de OS tratadas e disponibilidade percentual por mes.

Como funciona

Base bruta Relatorio exportado de OS em Excel.
Stage SQL Padronizacao de campos, datas e horas.
Qualidade Classificacao de OS abertas e intervalos invalidos.
Consolidacao Agrupamento de paradas sobrepostas por equipamento.
Indicador Disponibilidade mensal sem duplicidade de horas.

Trecho tecnico

A deteccao de sobreposicao compara o inicio da OS com o maior fim ja encontrado anteriormente para o mesmo equipamento. 

max(fim_parada) OVER (
  PARTITION BY equipamento
  ORDER BY inicio_parada, fim_parada, ordem_servico
  ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING
) AS fim_anterior_max

CASE
  WHEN inicio_parada < fim_anterior_max THEN true
  ELSE false
END AS os_sobreposta

Funcionalidades

Conversao de campos separados de data e hora em timestamps de inicio e fim.
Separacao de OS canceladas, abertas, sem inicio e com intervalo invalido.
Deteccao de OS sobrepostas por equipamento com funcoes de janela.
Consolidacao de intervalos sobrepostos em blocos unicos de indisponibilidade.
Quebra de intervalos atravessando meses para calculo mensal correto.
Calculo de disponibilidade percentual por equipamento e mes.
